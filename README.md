# B站稍后再看排序

适用于 **Microsoft Edge / Google Chrome** 的浏览器扩展。直接在 B 站原生「稍后再看」页面增加排序选项，支持按**视频发布时间**和**视频总时长**对完整列表排序，不需要打开独立的视频列表。

## 功能

- **全量排序**：基于 B 站返回的完整视频清单进行排序，而不是仅调整屏幕上已显示的部分卡片。
- **五种排序方式**：
  - **默认**：保持 B 站的默认列表顺序。
  - **发布时间：最新优先**。
  - **发布时间：最早优先**。
  - **总时长：短到长**。
  - **总时长：长到短**。
- **发布时间标注**：使用发布时间排序时，在视频封面左下角显示 `YYYY-MM-DD` 日期；其他排序模式下不显示。日期标注不遮挡视频点击区域。
- **原生页面体验**：沿用 B 站自己的视频卡片、排版、播放和管理操作，不创建替代网格，不自动滚动或刷新页面。
- **提前预加载**：页面打开时开始读取完整排序元数据，并调用 B 站原生列表加载方法预加载视频。预加载不改变原有排序，目的是减少用户选择排序后的等待。
- **默认状态**：每次打开或刷新网页均显示「默认」，不自动恢复上次选择的排序方式。
- **安全校验**：必须取得完整清单并与 B 站原生卡片逐项匹配才能完成排序；数据不一致时显示失败提示，不将部分卡片排序当作全量成功。

## 安装到 Edge

**推荐从 [GitHub Releases（最新版本）](https://github.com/PyRookie1/bilibili-watchlater-sorter/releases/latest) 下载为 Edge 准备的 ZIP 扩展包**，不要下载 GitHub 自动生成的 `Source code (zip)` 源代码压缩包。

1. 下载 Release 的 `bilibili-watchlater-sorter-edge-*.zip` 文件，并**解压**到固定文件夹（例如 `D:\Extensions\bilibili-watchlater-sorter`）。
2. 在 Edge 地址栏打开 `edge://extensions`，打开左侧或页面上的 **「开发人员模式」**。
3. 点击 **「加载解压缩的扩展」**，选择解压后**直接包含 `manifest.json` 文件**的文件夹。
4. 打开 [B站稍后再看](https://www.bilibili.com/watchlater/list#/list)，在原有「最近添加／最早添加」排序控件附近找到新增的「排序」下拉框。

**Edge 不能通过「加载解压缩的扩展」直接选择 ZIP 文件**；需要先解压。该 ZIP 已按扩展目录结构打包，解压后即可加载，无须运行构建命令。

### 更新

下载新版 Release ZIP，解压覆盖原文件夹，然后在 `edge://extensions` 中点击该扩展的 **「重新加载」**，最后刷新 B 站页面。请保留扩展所在的固定文件夹，不要移动或删除它。

## 使用说明

页面打开时显示「默认」。等待页面加载后，选择「发布时间」或「总时长」排序。发布时间模式会额外在封面显示发布日期；改用时长排序或「默认」会移除这些日期标注。

首次访问时，扩展需要通过 B 站自身的加载机制把尚未渲染的视频补齐到完整列表。**预加载可能产生额外请求并增加页面初始化资源开销**；若在预加载结束前立即切换排序，仍可能需要等待。

该扩展**只调整浏览器内当前页面的排序**，不会修改账号服务器上的稍后再看记录顺序。

## 适用范围与限制

- 支持 B 站稍后再看页面：`https://www.bilibili.com/watchlater/list#/list` 以及兼容路径。
- 需要先登录 B 站；依赖 B 站现有的列表 API、Vue 3 / Pinia 页面数据结构及原生加载方法。
- B 站页面结构、接口、筛选结果或登录状态发生变化，可能导致排序失败；此时界面会给出错误提示。
- 当前自动化测试覆盖数据完整性、排序、原生列表预加载和日期标注；**不能替代所有 Edge/B站账号环境下的实机兼容性验证**。

## 权限与隐私

- 使用 B 站现有登录状态请求 B 站自己的完整稍后再看数据。
- 扩展不直接读取 Cookie 值，不将观看列表上传至第三方服务器。
- 排序选择不持久化；每次打开页面都从「默认」开始。
- 扩展的作用域限于 B 站相关页面及其官方接口。

## 开发与测试

开发环境需要 Node.js 20 或更新版本，在项目根目录运行：

```bash
npm test
```

主要代码位于 `src/`：`preload.js` 提前读取数据；`full-native.js` 与 `native-intercept.js` 处理原生 Pinia 列表加载与排序；`date-overlay.js` 绘制发布日期标注；`content.js` 提供排序交互。

GitHub Releases 下载包仅包含扩展运行文件，开发人员可在仓库中查看完整源码与测试。
