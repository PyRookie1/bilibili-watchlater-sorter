# B站稍后再看排序

适用于 **Microsoft Edge / Google Chrome** 的浏览器扩展，直接在 B 站原生「稍后再看」页面增加排序选项，支持按**视频发布时间**和**视频时长**进行排序。

## 功能

- **原生排序按钮**：保留 B 站「最近添加」「最早添加」，用于恢复添加时间顺序。
- **四种扩展排序选项**：最新发布、最早发布、时长最长、时长最短。直接添加到 B 站「最近添加／最早添加」所在的原生下拉菜单中，不新增独立排序按钮、下拉框或菜单样式。
- **发布时间标注**：使用发布时间排序时，在视频封面左下角显示 `YYYY-MM-DD` 日期；其他排序模式下不显示。
- **原生页面体验**：沿用 B 站自己的视频卡片、排版、播放和管理操作。
- **提前预加载**：页面打开时开始读取完整排序元数据，并调用 B 站原生列表加载方法预加载视频。

## 安装到 Edge

**推荐从 [GitHub Releases（最新版本）](https://github.com/PyRookie1/bilibili-watchlater-sorter/releases/latest) 下载为 Edge 准备的 ZIP 扩展包**。

1. 下载 Release 的 `bilibili-watchlater-sorter-edge-*.zip` 文件，并**解压**到固定文件夹（例如 `D:\Extensions\bilibili-watchlater-sorter`）。
2. 在 Edge 地址栏打开 `edge://extensions`，打开左侧或页面上的 **「开发人员模式」**。
3. 点击 **「加载解压缩的扩展」**，选择解压后**直接包含 `manifest.json` 文件**的文件夹。
4. 打开 [B站稍后再看](https://www.bilibili.com/watchlater/list#/list)，打开 B 站原有的「最近添加／最早添加」排序下拉菜单，使用其中新增的四个选项。

**Edge 不能通过「加载解压缩的扩展」直接选择 ZIP 文件**；需要先解压。该 ZIP 已按扩展目录结构打包，解压后即可加载，无须运行构建命令。

## 使用说明

页面打开时沿用 B 站原生的添加时间顺序，无扩展「默认」按钮。在原生下拉菜单选择「最新发布／最早发布／时长最长／时长最短」进行全量排序。使用发布时间排序时，封面显示发布日期；切回原生的「最近添加／最早添加」或改用时长排序时，日期标注清除。

该扩展**只调整浏览器内当前页面的排序**，不会修改账号服务器上的稍后再看记录顺序。

## 适用范围与限制

- 支持 B 站稍后再看页面：`https://www.bilibili.com/watchlater/list#/list` 以及兼容路径。
- 需要先登录 B 站；依赖 B 站现有的列表 API、Vue 3 / Pinia 页面数据结构及原生加载方法。
- B 站页面结构、接口、筛选结果或登录状态发生变化，可能导致排序失败；此时界面会给出错误提示。
- 当前自动化测试覆盖数据完整性、排序、原生列表预加载和日期标注；**不能替代所有 Edge/B站账号环境下的实机兼容性验证**。

## 权限与隐私

- 使用 B 站现有登录状态请求 B 站自己的完整稍后再看数据。
- 扩展不直接读取 Cookie 值，不将观看列表上传至第三方服务器。
- 排序选择不持久化；每次打开页面都沿用 B 站原生排序。
- 扩展的作用域限于 B 站相关页面及其官方接口。

## 开发与发布规则

- 所有项目修改直接提交至 `main`，不创建功能分支。
- 每次 `main` 更新后自动运行测试、构建并发布最新 Edge 安装包。
- GitHub Releases 仅保留当前版本；新版成功发布后自动删除旧 Release 及其版本标签。
- 每次主动排序都重新读取完整视频列表，避免新增或删除视频后复用旧数据。
